# 📚 Tài Liệu Bổ Sung Dự Án LabRepair

Thư mục này dùng để lưu trữ các tài liệu chi tiết phục vụ cho báo cáo và đánh giá dự án:

1. **Sơ đồ thiết kế kiến trúc & CSDL**:
   - File xuất ảnh: `erd.png`, `architecture.png`
   - File thiết kế gốc: Draw.io (`.drawio`) hoặc dbdiagram.io (`.dbml`)
2. **Tài liệu kiểm thử API**:
   - File Postman Collection (`labrepair_api.postman_collection.json`)
   - File Environment (`labrepair_local.postman_environment.json`)
3. **Báo cáo đồ án**:
   - File Word / PDF đặc tả yêu cầu người dùng (SRS)
   - Báo cáo tiến độ tuần / sprint
